# ACCS developer memory

Private, human-readable vault for durable implementation context. Start with [MEMORY.md](MEMORY.md). Project scope and research decisions live in the separate `accs-memory` repository.

Record architecture decisions, setup facts, command conventions, integration contracts, and confirmed fixes with source paths and review dates. Mark plans as proposed and update notes when code changes. Do not store credentials, `.env` values, student records, or grievance content.
